Interactive quiz application with multiple categories and difficulty levels. 
 
## Features 
- Multiple categories 
- Difficulty levels 
- Score tracking 
- Timer functionality 
- Leaderboard 
 
## Tech Stack 
- **Frontend:** React.js, TypeScript 
- **API:** Open Trivia DB
